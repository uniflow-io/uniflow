You can self host Uniflow 💧 with npx 📦  
For this, just run the command below in your terminal to take Uniflow for a spin.

```
npx @uniflow-io/uniflow
```

Or install Uniflow with npm

```
npm install @uniflow-io/uniflow -g
uniflow
```

You can try loggin with the default admin account  

- email : `admin@uniflow.io`
- password: `admin`

Happy flowing. 🎉
